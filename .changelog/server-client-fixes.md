Fix server and client edge cases. `ChargeMiddleware`, `ComposeMiddleware` and the Gin, Echo and Fiber adapters keep a caller-set `ChargeParams.MppxScope` instead of overwriting it, and no longer write a response header after a handler hijacks the connection. Server misconfiguration (reserved `_mpp_nonce` metadata, a challenge request or description that cannot be encoded, no offers) now returns a 500 internal payment error instead of a client 400, whether or not the request carries a credential (`WritePaymentErrorWithChallenges` and its Fiber equivalent included); a request whose path or query alone makes the challenge header too large gets a 414 URI Too Long, classified by the new `server.ChallengeSerializationError`. An `mpp.ErrPaymentOutcomeUnknown` problem is sent without retry challenges (`server.IsPaymentOutcomeUnknown`), and `Transport` returns a 402 `payment-outcome-unknown` response to the caller instead of paying again. `ParseReceipt` also keeps `fundingCurrency` in `Receipt.Extensions` (the named field wins when formatting), so it round-trips through code that copies only extensions, as the mpp-tools conformance vector `success_receipt_extension_fields` expects. Also, a credential missing the required body digest gets an `invalid-challenge` problem with its fresh challenge. `server.New` rejects a nil method. `client.Client` keeps net/http's 10-redirect limit and follows cross-origin redirects of requests that carry no Payment credential. `client.Client` also refuses a cross-origin redirect when a request carries a Payment credential in any header field (checked after a custom `CheckRedirect` hook runs), and refuses to pay once a redirect chain has left the requested origin. `Transport` closes the request body on early errors without closing it twice, and returns `PaymentOutcomeUnknownError` when a request carrying a credential, including one the caller set, fails without a response; `client.Client` keeps that error when its `http.Client.Timeout` expires. A malformed credential that coincides with a failure to issue challenges in `ComposeCharge` and `ComposeMiddleware` now reports the internal error instead of a malformed-credential 402. Adds `mpp.ErrPaymentActionRequired` and `mpp.ErrPaymentOutcomeUnknown`, matching mppx. Relay calls without a configured `HTTPClient` time out after 30 seconds.
